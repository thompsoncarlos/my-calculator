# React Basics - Final Project (React Calculator)

This repository contains the final project and practical exercises developed during the **React Basics** course, taught by **Meta** experts on **Coursera**. This course is part of the *Meta Full Stack Developer* specialization program.

## 🚀 About the Final Project

The module 4 final project is a practical **React Calculator** application. The primary goal was to apply core concepts of state management, event handling, and dynamic component rendering to build an interactive, functional web app.

### 🛠️ Calculator Features

* Basic mathematical operations: addition, subtraction, multiplication, and division.
* Real-time application state updates using React hooks (`useState`).
* Reset result and clear user input fields.
* Input data manipulation and validation via form controls.

## 📚 Course Modules & Curriculum

The course is structured into 4 comprehensive modules:

### 🧩 Module 1: React Components

* Core concepts of React and environment setup in VSCode.
* Creating and composing reusable UI components.
* Structuring layouts using JSX syntax.
* Passing dynamic data between components using **Props**.

### ⚡ Module 2: Data and State

* Handling and managing **Events** in React applications.
* Error handling strategies related to event handling.
* Working with state to create dynamic and interactive UI.

### 🌐 Module 3: Navigation, Updating, and Assets in React.js

* Routing and navigation principles in Single Page Applications (SPAs).
* Conditional rendering and displaying partial views.
* Managing, bundling, and importing assets (images, CSS styles, etc.).

### 📱 Module 4: Your First React Application

* Hands-on development of the React Calculator mini-project.
* Consolidating skills and creating a portfolio-ready project.

## 💻 Getting Started / How to Run

1. **Clone the repository:**

   ```bash
   git clone https://github.com/your-username/your-repository-name.git
   ```

2. **Navigate into the project directory:**

   ```bash
   cd your-repository-name
   ```

3. **Install dependencies:**

   ```bash
   npm install
   ```

4. **Start the development server:**

   ```bash
   npm start
   ```

5. Open [http://localhost:3000](http://localhost:3000) to view the app in your browser.
